## Checked and found sound

- Mutations that the tests catch (listed in 4) cover the round-3 drift threshold, polish, pooled refinement, G5 label split, R1 serial check, R4 frozenset key, R3 `DEAD_TIME_UNCORRECTED`, N2 branch, N3 int tau, the pending and other-branch notes, the CHSH D3 range and its CLI print.
- `pooled_peak`: mixed declared delay or window is refused. Empty pairs are dropped. The bin count is capped. The tick is the gcd over pairs. Below `MIN_COUNTS`, None propagates to `capture_reweighted_s = None`, and the drift check returns no counts (not reachable with 100 coincidences per setting at Bell angles).
- `reweighted_s` cannot divide by an exact zero: the fitted offset is bounded by W + 5 sigma, so the capture stays > 0.
- CLI `simulate --deadtime-scan --rates` refuses 0, nan, negative and too many rates with `DadlError`. The deadtime CLI catches per-channel `DadlError`/`ValueError` and reports which channels failed.
- `corrected_chsh` refuses partial delay or dark coverage with a named `ValueError`. `chsh_model_label` and the CLI's hiding of it agree. API and CLI give the same CHSH result for the same seed (the CLI passes `setup.seed`; nothing else differs except the detector check, finding 3).
- `condition_mismatches` handles a missing temperature or bracket as round 3 ruled. `NO_VALIDITY` and the `dataset` record are present on all three analysis paths.
