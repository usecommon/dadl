Probe scripts are in `scratchpad/council/r2-prop/`. `common.py` builds in-memory `Calibration` objects with known
posteriors and a `CalibrationSet` from them. The other probes go through the package's own functions:
`calibrate_dark`, `calibrate_delay`, `write_artifact`, `CalibrationSet.load`, `corrected_visibility`,

## Checked and found sound

- **Joint draws.** Columns of one artifact share one permuted row index (without replacement when n <= rows, with replacement above). Artifacts are drawn independently from `SeedSequence(seed, artifact-ID words)`. `_dead_times`, `_capture` and `_pair_capture` each call `draws(n, seed)` and get identical rows, so one artifact's draws stay consistent across the corrections. The HOM high/low runs and all CHSH settings share each channel's dead-time draw, which is correct for one physical dead time. The count draws use a separate stream.
- **Stand-in columns are never drawn as a posterior.** Every `unidentified` column in dark, delay and deadtime-series is also a stand-in, so no unidentified column leaks into `JointDraws.columns`. An unidentified `afterpulse_tau_ps` is not stored.
- **Interval construction.** The interval is the 2.5% to 97.5% percentiles of the joint draws (Jeffreys Gamma for the coincidences and the off-peak sums, calibration rows for the nuisances). In a simulation from the forward model's own generative law (bell_visibility, dead time 80 ns, calibration sd 8 ns comparable to the statistical error, tau_hat redrawn per replicate, 300 replicates; p4_cover.py), the corrected interval covered 288/300 (96%). The statistical-only control covered 255/300 (85%). With sd 2 ns, both covered 288/300. The statistical and calibration parts (each with the other held at its point) add in quadrature to the joint sd, as expected.
- **Dark dead-time draws as used by the forward model.** 200 replicates at 20k cps for 0.2 s (p11_darkcov.py): interval 191/200 and draw quantiles 188/200. The point (the shortest gap) sits at the top of the draws by construction, so corrected intervals are asymmetric about the point. This is expected, not an error.
- **Refusals.** Misfit artifacts need `misfit_calibration`. Identical tag or file hashes are refused with no override. The CLI passes the hashes of the tags, the file and the setup inputs. `tagger_*` and `bias*` must be equal, ranges are checked, and the temperature tolerance is 0.5 K. These behave as documented (finding 4 covers the gaps).
- The loose-bound refusal (a dead fraction at the bound above 20%) is present in both the two-point and CHSH paths.
