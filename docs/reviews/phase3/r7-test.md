# Test quality (mutation testing, oracles, flakiness), round 7

Branch m4/series-deadtime at c7d3cf2. Everything ran on a `git archive HEAD` copy in
`scratchpad/council/r7-test/base/`, never in the repo. Files in `r7-test/`: the harness is `mutate.py` with
`mutations.py` (132 mutants, one exact-string replacement each, all checked to match exactly once), results
in `results.txt`, seed sweeps in `flaky.py` with output in `fl_*.txt`, the sign probe in `probes/p_sign.py`,
and baseline timings in `bl/`.

Each mutant ran the phase 3 test files for its module with `-x`. Forward, check, CHSH, HOM, fringe and
propagate mutants ran forward, propagate, hom, forward_check, config_and_cli, hardware_twin,
published_results, crosstalk, review_cycles and chsh_corrected. Deadtime and coverage mutants ran
calibration_deadtime and method_versions (plus calibration_pairs for coverage). Propagation mutants ran
test_propagation. CLI mutants ran all of these.

**Totals: 132 mutants. 84 killed, but 5 of those only by `test_method_versions`, which hashes the source
file and checks no behaviour. Behaviourally, 79 killed and 53 survived.** About 8 survivors are equivalent or
nearly equivalent (listed at the end). The ones that matter are below.
