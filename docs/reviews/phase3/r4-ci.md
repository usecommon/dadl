## Checked and found sound

- **Merge refuses missing or duplicate shards.** Both `merge` functions require one seed and one total. They check that the sorted `range`s tile 0..replicates exactly, so a gap, an overlap or a short final shard raises `ValueError` and the exit is non-zero. coverage also checks that `gate`/`at_least` agree across shards (council r1 Fix 11). If no artifact downloads, `shards/*.json` stays an unexpanded glob, `open()` fails, and the exit is non-zero.
- **A shard cannot silently produce zero replicates.** Neither gate catches exceptions per replicate: a failure in a worker propagates through `ex.map`/`fut.result()` and fails the step. In coverage, an empty shard range writes a zero-width range that the tiling check rejects. In propagation it raises IndexError (`mine[0]`). Each `covered` dict is non-empty (keys come from the truths), so `passed()` cannot pass vacuously.
- **Exit codes.** Gated runs return 1 when any result fails (coverage.py:636, propagation.py:436). Shards return 0 and are ungated by design, and the merge applies the gate. The propagation control (`CONTROL_REGIMES = ("chsh-dead-time",)`) is enforced in `passed()` and so at merge.
- **Seeds and `--jobs`.** Replicate i is always child (crc32(regime), i) of the seed. Shards use the CLI default seed, and merge enforces one seed. Results do not depend on `--jobs`: shard 1/12 gave identical counts with the Rust and Python backends and with HEAD and old code where unchanged.
- **Every regime runs in CI today.** dark 4/4, pairs 7/7, dcr 1/1, deadtime 2/2 (series-spad whole, passive-quench 12 shards plus merge), propagation 5/5 (chsh-dead-time 8 shards plus merge).
- **Action pins.** Each of the 5 action SHAs resolves to the commit its comment names (checked against the upstream repositories through the GitHub API: checkout v7.0.1, setup-python v7.1.0, maturin-action v1.51.0, upload-artifact v7.0.2, download-artifact v8.0.2). The workflow sets `permissions: contents: read`, uses `persist-credentials: false` everywhere, and has no `pull_request_target`. Dependabot covers actions, pip and cargo.
- **Other timeouts.** series-spad, chsh-dead-time shards, hom and hom-crosstalk all stay at or under about 31 min of 40-45 (table above). The round-3 branch search barely changes series-spad (measured 1.05x).
- **`test_method_versions` hashes only the six calibration modules**, so helpers they import (`calibration/base.py`, `stats.py`, `dark._dead_time` used by deadtime) can change under the same version. Noted only, since this is outside the CI lens and is the established design.
