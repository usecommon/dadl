# MCP agent surface

v0.2+ / seeking contributors. Not part of the MVP.

The design: five typed tools (`calibrate`, `measure`, `correct`, `fit`,
`explain`) in three permission tiers, with human approval tokens for
hazardous instrument writes, a tamper-evident audit log, and a simulator twin
that exposes the identical surface.

See `docs/design.md`, "Agent and MCP surface", "MCP tool schemas" and
"Security design".
